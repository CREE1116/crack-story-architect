# 바로 사용하는 스토리 온보딩 사이트 3종

각 폴더의 `index.html`을 열면 된다. `index.html`과 `styles.css` 두 파일만 복사하면 작동한다. 빌드·설치·외부 폰트·이미지·JavaScript가 필요 없다. 세 사이트의 이름·인물·규칙은 템플릿 동작을 보여주기 위한 독립적인 가상 예시이며 실제 작품의 정본이 아니다.

| 템플릿 | 적합한 작품 | 화면 구조 | 파일 |
|---|---|---|---|
| 전술 단말기 | 재난·SF·거점 생존 | 측면 목차, 입소 동선, 현재 위치·할 일, 현장 인원, 구역 규정 | [terminal/index.html](terminal/index.html) |
| 길드 게시판 | 판타지·길드·여행 | 접수원의 편지, 공개 의뢰서, 길드 사람, 접수 규칙 | [guild/index.html](guild/index.html) |
| 기록관 | 현대·일상·미스터리 | 인계 기록, 장소 도판, 근무 시작점, 당직 인원, 기본 규칙 | [archive/index.html](archive/index.html) |

세 형식 모두 홍보 카피·전체 설정 도감·숨은 정보·카운터·음악·입장 대기 연출을 넣지 않는다. 첫 진입에 필요한 것만 담는다. `details/summary`는 공개 안내를 접는 용도이며 비밀 내용을 넣는 곳이 아니다.

## 적용 순서

1. [설계 양식](../showcase-design-template.md)의 공개 정보 장부를 먼저 작성한다.
2. 한 폴더를 작품의 `site/`로 복사한다. 기존 사이트가 있으면 새 폴더에서 비교한 뒤 필요한 부분만 옮긴다. `deploy.py --scaffold`로 이 파일들을 덮어쓰지 않는다.
3. `<title>`, 설명 메타 태그, 기관명, 날짜, 시작 상황, 첫 인물, 규칙을 작품 정본으로 교체한다. 고정 역할은 해당 시작 세트가 허용하는 경우에만 쓴다. 예시 인물이 두 명이라는 이유로 실제 인원을 둘로 제한할 필요는 없다.
4. `styles.css`의 `:root` 색 변수와 아래 디자인 규칙에 따라 조정한다. 추가 정보는 ‘첫 행동에 필요한가’로 판단한다.
5. 이미지가 있으면 도판/이니셜 영역을 실제 공개 이미지로 교체한다. CSS 추상 도판은 생성 이미지가 아니며, 그대로 사용할 수도 있다. 지도는 실제 작품의 장소 연결과 맞춰야 한다.
6. 실제 작품 URL이 있을 때만 ‘작품 열기’ 링크를 추가한다. 미정 URL이나 클릭해도 아무 일 없는 버튼을 만들지 않는다.
7. 모바일과 데스크톱에서 읽고, 목차 이동과 접힌 기록을 열어 본다. 공개 범위와 배포는 [설계 지침](../../references/immersive-showcase-design.md)·[호스팅 지침](../../references/hosting-showcase-and-banner.md)을 따른다.

## 디자인 조정 규칙

### 전술 단말기

- 고정폭 서체는 번호와 상태 레이블에만 쓰고 한글 본문은 산세리프로 유지한다.
- 구역과 절차를 얇은 선으로 연결한다. 밝은 초록은 현재 위치와 중요 표시에만 사용한다.
- 세로 목차는 모바일에서 위쪽 가로 목차가 된다. 항목이 늘면 줄바꿈하며 가로 스크롤을 강요하지 않는다.
- `location` 도판을 수정하면 접근성 설명(`aria-label`)과 실제 안내 문구도 함께 고친다.

### 길드 게시판

- 종이색·잉크색·접수원의 목소리를 함께 유지한다. 문장을 홍보 문구로 바꾸지 않는다.
- 그림자와 도장은 문서의 물성을 보여주는 정도로만 둔다. 본문을 기울이거나 낡은 글자 효과로 지우지 않는다.
- 의뢰서를 펼치는 동작과 의뢰 수락은 구분한다. 이 템플릿은 내용을 읽을 뿐 실제 플레이 상태를 바꾸지 않는다.
- 모바일에서 한 장씩 읽도록 의뢰 카드를 한 열로 배치한다. 내용 길이를 맞추려 공백이나 설정을 덧붙이지 않는다.

### 기록관

- 큰 명조 제목, 작은 날짜·서명, 읽기 편한 산세리프 본문으로 위계를 만든다.
- 첫 도판은 장소와 분위기만 전달한다. 중요한 상황이나 지시를 그림 안에만 넣지 않는다.
- 인물의 이니셜은 사진 없는 상태를 위한 대체 디자인이다. 사진을 붙일 때 공개 첫인상과 충돌하지 않는 장면을 선택한다.
- 초반 인원만으로 시작한다. 장편 설정이 있다는 이유로 필터·검색·전체 도감을 자동 추가하지 않는다.

## 확인한 범위

초기 템플릿은 1280px 데스크톱과 390px 모바일 첫 화면을 브라우저에서 확인했다. 작품에 맞춰 문구와 이미지를 교체하면 줄바꿈과 공개 범위 검토를 다시 수행한다. 원본과 다른 OS에서는 기본 서체가 달라질 수 있다.
