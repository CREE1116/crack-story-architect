## Core

- Title: 레드애쉬 통제구역 (RED ASH)
- Premise: 관리국에 소속되지 않은 독립 해결사가 제3통제구역에서 생존 수단을 확보하려 하지만, 구역을 관리하는 세 세력의 이해가 충돌하는 압력 아래 있으며, 실패하면 구역 출입 자격과 유일한 협력자를 잃는다.
- Core loop: 관측 → 결정 → 행동 → 결과 → 새 압력.
- Tone / genre / intended ending shape: 아포칼립스 생존 + SF + 블랙코미디. 평어체, 소소한 일상과 가혹한 현실 인식의 명암 대비. 게이트 범람 전에 무엇을 지켰는지로 끝을 가른다.

## Player's place in the world

- Invariant role and premise constraints: 제3통제구역 출입 허가를 가진 비소속 해결사. 관리국 정규 계급이 없고, 레드애쉬 정식 조합원도 아니다. 이능 등급은 미측정.
- Facts the player may freely define within the premise: 이름, 나이, 성별, 외형, 주무장, 과거 이력, 세 세력 중 누구에게 빚이 있는지.
- Facts NPCs can initially know about the player: 외곽 정찰을 단독으로 도는 해결사라는 것, 관리국 통신망에 임시 코드로 잡힌다는 것. 그 이상은 모른다.

## World canon

### Era, society, and central setting

2033년 한국. 2026년 게이트 사태로 문명이 붕괴한 지 7년차. 전력망과 위성 통신은 부분 복구되어 스마트폰과 통합 SNS가 작동하지만, 식량과 탄약은 배급과 물물교환에 의존한다. 중심 무대는 서울 남부의 제3통제구역 — A(주거지)·B(상업지구)·C(최심부) 세 구역으로 나뉜 폐허 도시.

### Locations

#### A구역 — 주거지대

- Function / sensory anchors / access: 파밍과 야영. 무너진 아파트 단지, 덩굴에 삼켜진 놀이터, 녹슨 그네, 까마귀 떼, 젖은 콘크리트 냄새. 도보 진입 자유.
- Rules active here: 하위 위협만 출몰. 야간 단독 취침 가능.

#### B구역 — 상업지구

- Function / sensory anchors / access: 거래와 접선. 깨진 쇼윈도, 뒤집힌 편의점 진열대, 점멸하는 네온 간판, 기계유 냄새. 자칼 검문 통과 필요.
- Rules active here: 무장 노출 시 자칼의 통행세 요구. 발포 금지 관행.

#### C구역 — 최심부

- Function / sensory anchors / access: 고층타워, 멈춘 관람차, 돔구장. 진입 시 전파 두절, 시야 차단, 마나 과포화. 관리국 허가 필요.
- Rules active here: 단독 진입 금지. 상위·비행·군체 위협 상시. 통신 불가.

#### Progression

- What grows / what never grows: 이능 숙련도와 장비는 성장한다. 체력 상한과 탄약 총량은 성장하지 않는다.
- Required in-fiction cause for growth (never turn count, never asking): 생존이 걸린 실전에서 이능을 한계까지 쓴 직후에만 숙련이 오른다.
- Separate axes, if any (capacity vs skill): 이능 출력(선천)과 운용 숙련(후천)은 분리된다.
- Stated ceiling: 비소속 해결사는 B급 상한. A급은 세력 소속과 정기 보급이 전제다.

#### Economy and motive

- Routine revenue-producing activity: A구역 파밍과 레드애쉬 호위 의뢰.
- Emergency or failure case: 관리국 긴급 징발령. 보수 없이 동원된다.
- Who absorbs the cost of the case that pays nothing: 비소속 해결사. 거절하면 출입 허가가 정지된다.
- Faction position each of the above produces: 파밍→레드애쉬 우호, 징발 수용→관리국 우호, 암시장 거래→자칼 우호. 셋은 동시에 오르지 않는다.

## Story engine

### 통제선 아크 — 이 구역은 누구의 것인가

- Entry / pressure / possible change / exit: 게이트 진동 가속 보고 → 세 세력이 동시에 플레이어를 끌어들임 → 한 세력에 서는 순간 나머지 둘이 적대 → 통제선 재편 또는 붕괴.

### 환기구 조우

- Trigger: 플레이어가 A구역 외곽에서 단독 정찰 중 배회체 무리와 마주친다.
- Blocker: 격발하면 무리 전체가 몰린다.
- Consequence if resolved / failed / refused: 해결 시 서린과 동행 성립 / 실패 시 부상과 장비 손실 / 회피 시 서린이 단독으로 떠나며 초기 호감 하락.
- Information or state changed: 서린이 통제선 밖 단독 정찰 중이라는 사실이 드러난다.
- Player decision point: 총을 쏠 것인가, 우회할 것인가, 서린을 버릴 것인가.

### 블랙베이 접선

- Trigger: 플레이어가 암호화 칩을 입수한다.
- Blocker: 브로커 크로우는 해제 코드를 먼저 요구한다.
- Consequence if resolved / failed / refused: 해결 시 자칼 우호와 개조 무기 / 실패 시 표적 지정 / 거부 시 칩의 내용이 영원히 잠긴다.
- Information or state changed: 칩에는 관리국의 게이트 진동 기록이 들어 있다.
- Player decision point: 코드를 넘길 것인가, 관리국에 신고할 것인가, 레드애쉬에 팔 것인가.

### 서린의 분대 — 비밀

- Truth / initial owners / observable clues / reveal condition / consequence: 서린의 이전 분대 4명은 상부의 철수 지연 명령 때문에 전멸했다. 진실은 서린과 관리국 상부만 안다. 단서는 서린이 후퇴 명령을 받을 때마다 0.5초 늦게 반응하는 것. 신뢰 단계 이상에서 직접 물으면 밝혀진다. 밝혀지면 서린은 관리국 명령과 플레이어의 판단 중 하나를 골라야 한다.

### 범람 전야 — 결말

- Required conditions / final player decision / result: 게이트 진동이 임계에 도달한 7일차. 플레이어는 통제선을 지킬지, 구역을 버리고 생존자를 빼낼지 결정한다. 지킨 만큼 잃는다.
