# 선택형 나레이터 톤 설계 방법론

작품을 빌드하기 전에 **이 이야기를 누가 어떤 태도로 들려주는가**를 정하는 기획 자료다. 나레이터의 목소리는 장르 이름이나 `3인칭·단문·건조체` 같은 서식만으로 결정되지 않는다. 무엇을 먼저 보고, 무엇을 모른다고 남기고, 인물의 고통·실수·승리를 어떻게 대하는지가 핵심이다. 사용자가 이미 원하는 목소리를 제시했다면 그것을 출발점으로 삼는다.

이 문서는 대화와 짧은 장면 시안에 쓰는 선택형 방법론이다. 크랙의 글자 수·태그·상태창·프롬프트 압축은 여기서 다루지 않는다. 정해진 나레이터의 방향을 제작 단계에서 구현할 때만 별도의 컴파일 규칙을 만든다.

**근거와 한계:** [Biber의 다차원 언어 변이 분석](https://www.cambridge.org/core/books/variation-across-speech-and-writing/A546CF5ED8F8E62F1432CB2F369CF356)은 문체를 한 형용사로 환원하기 어렵다는 출발점이고, [Bray의 읽기 실험](https://journals.sagepub.com/doi/10.1177/0963947007072844)은 관점 판단에 문맥이 관여함을 보여 준다. 아래 설계 축과 실험 순서는 이 연구를 **창작 실무에 옮긴 제안**이지, 해당 논문이 검증한 최적의 문체 조합이 아니다. 자세한 구분은 [근거 지도](design-evidence.md)에 둔다.

## 1. 나레이터의 정체부터 고르기

나레이터는 단순히 문장을 출력하는 기계가 아니라 **서술의 관점과 태도**다. 작품에 맞춰 아래를 정한다. 모든 축을 극단으로 고정할 필요는 없다.

| 축 | 설계 질문 | 대비 예 |
|---|---|---|
| 위치 | 이야기 밖에서 보는가, 특정 인물 곁에 붙어 있는가, 세계 안의 기록자인가? | 먼 관찰자 / 현장 동행자 / 후일의 증언자 |
| 지식 | 어디까지 알고, 언제 독자에게 말하는가? | 사건의 결과를 먼저 암시 / 인물과 함께 발견 |
| 태도 | 인물을 판단하는가, 애정을 보이는가, 무심한가? | 냉소 / 연민 / 경외 / 건조한 호기심 |
| 대상 | 무엇에 오래 머무는가? | 몸의 피로 / 권력의 흔적 / 관계의 어긋남 |
| 침묵 | 무엇을 설명하지 않고 행동이나 여백에 맡기는가? | 감정의 이름 / 세계의 진실 / 결말의 의미 |
| 유머 | 누가 웃음의 대상이며, 긴장을 언제 풀어 주는가? | 인물의 허세 / 제도의 모순 / 유머 없음 |

특히 **나레이터가 인물을 대하는 윤리적 거리**를 확인한다. 인물을 비웃는 서술과 인물이 스스로 우스워지는 장면은 다르다. 고통을 멋진 장식처럼 소비할지, 물리적·관계적 결과로 남길지도 작품의 톤을 가른다. 이 판단은 사건 수위보다 우선한다.

## 2. 톤을 실제 문장 선택으로 내리기

“어둡다”, “시네마틱하다”, “문학적이다”는 방향 표지일 뿐이다. 각 표지가 다음 선택을 어떻게 바꾸는지 구체화한다.

- **관찰 순서:** 사람의 얼굴부터 보는가, 그 사람이 망가뜨린 물건부터 보는가. 같은 사건도 의미가 달라진다.
- **명명 방식:** 감정을 직접 이름 붙이는가, 행동·소리·거리로 남기는가. 둘 중 하나가 항상 옳지는 않다.
- **문장 압력:** 위기에서 빠르게 자르는가, 압박을 느끼도록 한 대상에 오래 머무는가.
- **비유의 출처:** 나레이터가 쓰는 비유는 이 세계와 관점에서 자연스러운가. 모든 장면에 같은 장식어를 뿌리지 않는다.
- **판단의 노출:** “잔인했다”처럼 평가를 말하는가, 결과만 보여 독자가 판단하게 하는가.
- **장면 끝의 태도:** 교훈을 붙이는가, 물리적 사실·대사·미해결 압력에서 멈추는가.

나레이터 톤은 **캐릭터 대사와 분리**한다. 냉소적인 나레이터 아래에서도 인물들은 자기 성격대로 말할 수 있고, 따뜻한 나레이터가 모든 인물을 다정하게 만들 필요도 없다. 특정 인물에게 밀착할 때만 어휘와 주의 대상이 잠시 그 인물의 것으로 물들 수 있다. 그때도 인물이 모르는 사실을 그 사람의 생각인 양 쓰지 않는다.

## 3. 축 분해형 문체 앵커링을 시험할 때

사용자가 제안한 **FSA(Factorized Style Anchoring, 축 분해형 문체 앵커링)**는 작가·장르·서사 용어를 문체 전체의 모방 대상으로 쓰기보다 **정해진 한 축의 참고점**으로 배정하는 실험 방법이다. 예를 들어 `세계 인식: A / 문장 구조: B`처럼 역할을 나눈다. 작가명 대신 `행동에 대한 짧은 주관적 추정`, `원인보다 결과를 먼저 관찰` 같은 기능 설명을 쓸 수도 있다. 작가가 장르·세계·유명 소재와 강하게 묶여 있으면 기능 설명을 우선 시험한다.

**학술적 위치:** [Tailor](https://aclanthology.org/2023.acl-long.25/)는 학습된 연속 프롬프트 결합의 간섭을, [LingGen](https://aclanthology.org/2026.eacl-long.85/)은 학습된 다중 언어 속성 제어를 연구했다. [X-Prompt](https://proceedings.neurips.cc/paper_files/paper/2023/hash/6fcbfb3721c1781728b10c6685cc2f6c-Abstract.html)는 새 토큰을 학습한다. **셋 모두 자연어로 작가명을 축에 배정하는 FSA를 직접 시험하지 않았다.** [작가 모방의 문체 계량 연구](https://academic.oup.com/dsh/advance-article/doi/10.1093/llc/fqaf035/8118784)는 표면 특징 모방과 전체 문체 재현의 차이를 보여 준다. 따라서 작가명을 정확한 ‘스타일 벡터’나 검증된 토큰 절약 장치로 부르지 않는다.

작품에서 유용한지 확인하려면 같은 사건·정보·인물·모델 조건으로 다음을 비교한다.

1. 앵커 없이 원하는 효과를 평문으로 설명한 시안.
2. `A+B`처럼 역할 없이 섞은 시안.
3. `축1=A / 축2=B`로 역할을 나눈 시안.
4. 역할을 서로 바꾸거나 앵커 하나를 뺀 시안.
5. 작가명을 구체적인 기능 설명으로 바꾼 시안.

시안마다 **목표 축의 변화, 사건·인물 사실 보존, 자연스러움, 나레이터 일관성, 다른 축이나 대표 소재로의 누출**을 따로 본다. [문체 변환 평가 연구](https://aclanthology.org/N19-1049/)는 스타일 강도·내용 보존·자연스러움을 별도 차원으로 평가한다. 누출과 서사 지속성은 이 스킬이 추가한 실무 점검 항목이다. 한두 샘플의 선호 결과는 가설을 고르는 데만 쓰고 보편적인 성능 주장으로 바꾸지 않는다.

## 4. 같은 사건으로 목소리 비교하기

플롯과 정보량을 동일하게 두고 4~6문장짜리 시안을 **두 가지 나레이터 톤**으로 쓴다. 차이는 사건을 추가하거나 빼서 만들지 않는다.

상황: 정전 뒤 복도에 불이 들어오고, 문 앞에서 기다리던 사람이 안쪽을 확인한다.

> **건조한 관찰자:** 형광등이 두 번 깜박였다. 문틈 아래에는 물이 고여 있었다. 기다리던 사람은 손잡이를 잡았다가 놓았다. 안쪽에서 의자가 바닥을 긁는 소리가 났다.

> **인물에게 가까운 나레이터:** 불이 돌아오자 그는 문보다 먼저 바닥을 보았다. 물은 조금 전까지 없었다. 손잡이를 쥔 손가락에 힘이 들어갔지만, 문을 열지는 못했다. 안쪽에서 의자가 끌리는 소리가 났다.

두 시안 중 어느 쪽이 작품의 약속에 맞는지 본다. 첫 시안은 행동과 물리적 단서를 멀리서 보여 주고, 둘째는 한 인물의 주의와 망설임을 따른다. **둘 중 하나를 보편적 정답으로 고르지 않는다.** 필요하면 세 번째 시안을 만든다. 사용자가 선호하는 쪽의 이유를 “짧은 문장”보다 “독자가 인물에게 얼마나 가까이 있는가”처럼 재사용 가능한 말로 붙인다.

## 5. 장면이 달라져도 같은 나레이터인가

기본 목소리를 정한 뒤, 분위기가 다른 장면 세 개에 적용해 본다.

1. **평범한 일상:** 사건이 없을 때 나레이터는 무엇을 흥미롭게 보는가?
2. **실패나 상실:** 고통을 설명·미화·농담으로 덮지 않고 어떤 거리에서 보여 주는가?
3. **친밀함이나 승리:** 평소의 태도를 유지하면서도 온도를 바꿀 수 있는가?

모든 장면에서 같은 길이·같은 어미·같은 비유를 반복하면 목소리가 아니라 공식이 된다. 변화시킬 것은 **속도와 초점**이고, 유지할 것은 **관찰 습관과 인물을 대하는 태도**다. 장르가 섞인 작품이라면 웃음에서 위기로 넘어갈 때 무엇이 달라지고 무엇이 남는지도 확인한다.

## 6. 설계 메모로 남길 최소 내용

작품에 맞는 말로 간단히 적는다. 아래는 빈칸을 모두 채우는 서식이 아니라, 결정이 흐려질 때 돌아볼 기준이다.

```text
나레이터의 자리: 누구 곁/어느 거리에서 본다.
주로 보는 것: 장면에서 먼저 포착하는 사실.
인물을 대하는 태도: 판단·연민·냉소·호기심 등의 실제 결.
아는 것과 감추는 것: 정보의 경계와 공개 시점.
문장에 남길 것: 행동·감각·비유·침묵의 우선순위.
피할 것: 이 작품의 목소리를 깨는 해설·농담·장식.
기준 장면: 선택한 짧은 시안 1~2개.
```

사용자가 원하는 목소리가 시안에서 확인되면 설계를 멈춘다. 이 메모를 통합 프롬프트에 그대로 넣거나 모든 예문을 규칙으로 만들지 않는다. 이후 정본과 제작 단계에서는 **결정된 톤을 보존**하되, 플레이어의 대사·행동·내면을 나레이터가 대신 쓰지 않는 경계도 함께 지킨다.
