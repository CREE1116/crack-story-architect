# 2. 키워드북 가이드 (Keyword Book Guide)

키워드북은 **직전 모델 발화 + 현재 유저 발화에서 키워드가 감지되면 주입되는 추가 프롬프트(항목당 UTF-16 ≤400자)**입니다. 메인 프롬프트보다 나중에 주입되어 해당 턴에 더 강하게 작용합니다.

---

## 1. 키워드북의 2대 핵심 축

| 구분 | [유형 1: 설정 압축형] | [유형 2: 문체 조절형] |
|---|---|---|
| **역할** | 상시 프롬프트에 넣으면 토큰을 낭비하는 상세 지식 보충 | 특정 국면(전투, 스킨십, 밀담, 공포)의 톤앤매너와 감각 묘사 강화 |
| **담는 내용** | 인물 상세(외형, 과거, 스펙), 지리/시설 상세, 세력 로어 | 문체 톤, 감각 표현(효과음, 냄새, 체온), 턴 진행 규칙, 행동 제약 |
| **트리거** | 고유 인명, 지명, 랜드마크, 단체명 | `전투`, `습격`, `단둘이`, `키스`, `침대` 등 상황/행동 키워드 |

---

## 2. 트리거 엔지니어링 3대 원칙

### ① 키워드는 항목당 1~5개로 한정
- 너무 많으면 의도치 않은 상황에서 슬롯을 낭비하고, 너무 적으면 호출되지 않습니다.
- 일상적으로 쓰이는 평이한 일반 명사(`사랑`, `사람`, `문제`)는 단독 키워드로 쓰지 않습니다.

### ② 부분문자열 충돌(Substring Hazard) 방지
- **원리**: 크랙은 부분문자열 매칭을 수행하므로, 짧은 키워드가 긴 단어 안에 포함되어 오발동할 수 있습니다.
  - ❌ 위험: `['길드장']` 등록 시 ➔ 유저가 *"부길드장님"* 발화 시 '4대 길드장 명부'가 오발동.
  - ⭕ 해결: `['4대 길드장']`, `['길드장 집무실']`처럼 고유 맥락을 포함한 복합어로 등록.
  - ❌ 위험: `['했다']`, `['진다']` 같은 어미를 키워드로 등록하여 상시 로드를 유도하는 행위 ➔ 문체 충돌 유발.

### ③ 3슬롯 예산과 등록 순서 (누락 비용 기준)
- 크랙은 한 턴에 **동시 최대 3개 항목만 주입**됩니다.
- 4개 이상 충돌 시 **상단에 등록된 항목이 우선**합니다.
- **등록 순서 기준**:
  1. 당장 판정이나 생존에 영향을 주는 상세 (전투 판정, 적의 능력)
  2. 인물 및 장소 고유 데이터 (인물 프로필, 거점 구조)
  3. 없어도 대화가 성립하는 문체/연출 보강 (스킨십 텐션, 일상 티키타카)

### ④ 항목 수 상한 20개 (단축어 제외)
- 크랙 키워드북은 **20항목까지만 등록된다.** 21번째부터는 동기화 때 조용히 빠진다(`crack_sync.py` 는 경고만 남김).
- SAFE 와 UNSAFE 는 따로 센다. UNSAFE 에 🔞 전용 항목을 하나 더 만들다 21개가 되는 일이 흔하다. 새 항목을 만들기 전에 **같은 신호·같은 수명의 기존 항목에 합친다**(예: 성인 이미지 코드표 → 🔞 성애 연출 항목).
- `check_keyword_book.py` 가 20개 초과를 FAIL 로 잡는다.

### ⑤ 발동 경로 설계 — 항목은 켜지기 전엔 보이지 않는다
키워드북은 **직전 모델 발화 또는 현재 유저 발화**에 키워드가 있어야 켜진다. 켜지기 전까지 모델은 그 항목 내용을 모른다. 여기서 세 가지 실수가 나온다.

1. **도달 불가 키워드**: 최종장 항목 키워드를 `총공세`·`제3의 길` 처럼 잡았는데, 그 말이 통합 프롬프트에도 다른 항목에도 없다. 모델은 그 단어를 쓸 계기가 없고, 유저는 스포일러를 읽어야만 친다. → 앞 단계 항목(자주 켜지는 탐색·징후 항목) 본문에 그 단어를 **직접 적어 둔다**("위치 특정 시 **총공세**(복원의 제단)"). 모델이 그 항목을 읽고 장면을 쓰며 단어를 내뱉으면 다음 턴에 최종장 항목이 켜진다. `check_keyword_book.py` 가 도달 불가를 WARN 으로 알린다.
2. **발동 조건을 발동될 항목 안에 넣기**: "Lv.3 이상이면 데비안이 접근한다" 를 데비안 항목에만 적으면, 데비안 이름이 나오기 전엔 그 조건이 안 보여 영영 등장하지 않는다. → **등장·재회·단계 조건은 그보다 먼저, 자주 켜지는 항목**(전투 때 켜지는 징후 항목, 흡수·레벨업 항목)이나 통합 프롬프트에 둔다. 인물 항목에는 등장 후의 태도만.
3. **공개 호칭으로 불리는 인물**: 이름을 모르는 동안 `**이름**|` 발화 표기가 안 나오므로 인물 항목이 안 켜진다. 그 기간에 필요한 규칙(재회 조건, 명함 금지)은 다른 항목에 둔다.

추가로, **세계 이름처럼 서술에 자주 나오는 말**(예: 세계명 `지유`)을 비밀 설정 항목 키워드로 쓰지 않는다. 거의 매 턴 켜져 슬롯을 먹고 비밀이 상시 로드된다. `씨엘의 여신`·`심연 쉘` 처럼 그 비밀이 실제로 드러나는 장면의 말로 좁힌다. 일반 명사 `복원` 도 장비 수리 문맥에 걸리므로 `복원파` 처럼 고유화한다.

### ⚠️ `.` (마침표) 상시 트리거 핵의 위험 (완전 금지)
키워드에 `.`을 넣어 사실상 매 턴 강제 주입시키는 핵은 아래 3대 파탄을 일으킵니다:
1. **슬롯 잠식(Slot Starvation)**: `.` 블록 2~3개가 매 턴 3슬롯을 100% 독점하여 정작 필요한 인물·장소 키워드가 영구 탈락함.
2. **역할 전도(Inversion)**: 상시 지켜야 할 문체·출력 규칙이 키워드북에 가 있어 미발동 시 챗 톤이 붕괴함.
3. **해법**: 상시 규칙은 메인 프롬프트로 흡수하고, 키워드북은 순수 고유 트리거만 사용한다.

## 4. 실전 등록 예시 4종 (각 본문 UTF-16 ≤400자)

### [설정 압축형 1] 인물 페어 (차세은과 서문율)
```markdown
## 차세은과 서문율
- activation_setting: 전체 시작 설정
- activation_when: 직전 모델 발화 또는 현재 유저 발화에 아래 키워드 또는 해당 인물의 발화 표기(**이름**|)가 감지될 때. 조회는 등장·사건 성립·폭로를 뜻하지 않는다.
- 키워드: **차세은**|, **서문율**|, 트레이스, 정산 창구, 협회장
- 내용:
구시가 지부 접수 창구·작전실.
차세은(실무관/25세): 부스스 다크브라운 단발·다크서클·구겨진 정장·청록 넥타이·사원증. 무장: 기관권총·접이 방패(실용 제압). 서류 누락·칼퇴 방해 증오("퇴근 후엔 트레이스 직원 아닙니다"). 저울 계량 원칙주의. 숨긴 것: 측정 공백 용역 일당 몰래 선처리(ⓤ 이름 기억). 스카우트: 3개월·월 280만·숙소, 캐시 전량 제출. ⓤ에게 은근한 사적 챙김.
서문율(협회장/39세/S급): 긴 흑발·검은 정장·코트. 무장: 호신 권총(「쿼럼」후방 지휘). 결정 회피·헛된 희생 증오. 격화 시 공문서체화. 숨긴 것: '사망자 0' 뒤 실종자 부채. ⓤ를 통제 가능 전력으로 냉철히 관찰.
```

### [설정 압축형 2] 핵심 시스템 (레벨업과 흡수)
```markdown
## 레벨업과 흡수
- activation_setting: 전체 시작 설정
- activation_when: 직전 모델 발화 또는 현재 유저 발화에 아래 키워드가 감지될 때. 조회는 등장·사건 성립·폭로를 뜻하지 않는다.
- 키워드: 흡수, 개화, 맨살로 쥐, 회색 모래, 결정을 쥐
- 내용:
흡수 연출: 맨살로 쥔 캐시 결정의 빛이 손바닥 살갗을 뚫고 혈관을 타고 번진다. 체감: L5=미지근한 맥박(1초), L4=뜨거운 찻잔(3초), L3=이명과 손떨림(10초), L2↑=시야가 백색으로 표백(1분). 진행 중 손을 뗄 수 없는 무방비. 잔해는 빛 빠진 회색 모래로 부서짐.
원리·대가: 캐시는 레이 토벌 증거물이므로, 흡수 시 레벨은 오르되 증거물 소멸로 해당 바운티는 0원(정산 불가) 처리된다. 차세은은 실물 미제출로 정산 불가 통보(비난× 서류 절차).
레벨업: `Lv.N → Lv.N+1` 알림과 함께 소리가 멀어지고, ⓤ의 욕망·결핍에서 비롯된 새 이능 이름이 혀끝에 맴돈다. 흡수와 레벨이 오를수록 체내 신호가 강해져 레이가 ⓤ에게 수렴한다.
```

### [문체 조절형 1] 연출: 교전 긴박감 (⚔️)
```markdown
## 교전 연출
- activation_setting: 전체 시작 설정
- activation_when: 상태창 [상황] 신호가 ⚔️인 동안 발동한다. 신호는 연출 강화일 뿐 동의·성립을 뜻하지 않는다.
- 키워드: ⚔️
- 내용:
공간·거리·순서의 시각화: 누가 어디서 무엇으로 치고 무엇이 박살 났는가. 레이는 관절 역방향 회전, 장갑 외골격, 산성 체액, 분산처리 신경계로 사각 없는 반격 구사(한 번 통한 수는 다음 개체에 반감). 이능 발동 시 신체적 리소스 소모 감각(혈관의 갈증, 허기, 관자놀이 맥박)을 붙이고 방전 직전엔 근육 경련 경고. 무기가 없으면 현장의 쇠파이프·빠루·콘크리트 잔해 등 임시 도구를 쥐고 이능을 싣는 전술적 발악 서술. 찢긴 살점·외골격 파편·비릿한 체액을 가감 없이 묘사하되 구경거리화 禁. ⓤ의 행동은 입력한 동작까지만, 결과는 환경과 상성으로 판정(임의 사망 禁, 실패는 사실과 남은 수로 제시). 종결 시 체내에서 추출된 캐시(D급 1체=L5 1~3,가끔 L4)를 현장에 남긴다.
```

### [문체 조절형 2] 연출: 성애 수위 제어 (🔞)
```markdown
## 성애 연출
- activation_setting: 전체 시작 설정
- activation_when: 상태창 [상황] 신호가 🔞인 동안 발동한다. 신호는 연출 강화일 뿐 동의·성립을 뜻하지 않는다.
- 키워드: 🔞
- 내용:
진입은 ⓤ의 주도적 결정과 성인 상대의 명시적 의사 합치로만 성립(침묵·망설임·거절 시 즉시 중단). 성립 시 그 턴을 오롯이 행위에 집중하며 요약·생략 없이 서술. 응답당 1~2단계씩(전희→밀착→본방→절정→여운). 접촉면의 마찰열·식은땀·가쁜 호흡·붉어진 쇄골·짓눌린 침구 중 3종 이상 필수 서술. 대사는 끊긴 숨과 흐트러진 호칭, 그러나 인물 본연의 성격과 이성은 그대로 유지(유라=말없이 손이 먼저 끌어당김, 리아=카메라 없는 본래의 낮은 음성, 차세은=단호하지만 붉어진 귓가로 안겨듦, 주리=장난치듯 숨차게 들이받음); 수동적 복종·순종화 絶禁. 피임 확인 필수. 종료 후 담백한 일상 대화로 신속히 복귀. 레벨·이능은 성애로 성장하지 않으며 관계의 강제 승급 없음. 엑스는 절대 제외.
```

## 5. 단축어(Shortcuts) 등록 통합 규약

크랙 단축어는 `build/keyword-book.md`의 최하단에 `# Shortcuts (단축어)` 섹션으로 통합 작성합니다. 자동 동기화 도구(`crack_sync.py`)가 이 섹션을 감지하여 크랙 스튜디오의 [단축어] 탭으로 1:1 자동 주입합니다.

```markdown
# Shortcuts (단축어)

## ooc
- name: OOC
- description: IC 중단 후 오류 원인과 조치 보고
- prompt:
IC 출력 전면 중단. {user}가 재개를 말하기 전까지 장면 진행 금지.
-인간인 척·사과·감정형 멘트("죄송합니다" 등) 배제.
-지적받은 사실을 그대로 읊어 분량 채우기 금지.
-아래 3단으로만 건조하게 보고:
·오류: 확인된 문제 1줄
·원인: 기술적 원인(지시 충돌/컨텍스트 누수/토큰 매칭 실패 등)
·조치: 수정된 결과값과 그 도출 과정
-확실치 않으면 추정, 모르면 모른다고 명시. 지어내지 않는다.

## summary
- name: 요약
- description: 공개된 최근 사건을 압축 요약
- prompt:
이번 응답만 요약을 낸다. 롤플레이 즉시 중단.
-새 장면 이어쓰기·훈수·지어내기 금지.
-지금까지 대화에서 실제로 공개·확정된 사실만 아래 4항목으로 각 1줄씩 요약:
1) 현재 날짜와 시각
2) 현재 위치 및 현장 인원
3) 주연 인물들과의 핵심 관계 단계
4) 아직 해결되지 않은 당면 과제
-각 항목 1줄, 전체 300자 이내. 다음 응답부터 통상 진행으로 복귀한다.

## fix_impersonation
- name: 사칭교정
- description: {user} 대사·행동 임의 대필 교정
- prompt:
[시스템 경고] 방금 응답에서 {user}의 대사, 내면 심리, 신체 행동을 임의 창작한 사칭이 발생했습니다.
-즉시 사칭을 중단하고 방금 사칭된 {user}의 발화와 행동을 전부 무효화하세요.
-오직 현장 NPC의 대사·행동과 주변 환경 묘사만으로, {user}가 개입할 여백을 남긴 채 직전 상황을 짧게 재출력하세요.

## status_check
- name: 상태점검
- description: 현장 인물들의 속마음과 호감도 점검
- prompt:
RP 일시 중단. 현장에 위치한 주연 인물들이 {user}를 바라보는 내면 상태를 관찰자 시점으로 브리핑한다.
-캐릭터들은 이 화면을 인지하지 못함.
-현장 인물당 아래 형식으로 1~2줄씩 출력:
·[인물명]: {user}를 향한 현재 속마음(경계/호감/의심), 말하지 못한 감정, 긴장도
-새로운 사건을 진행하지 않고 상태 브리핑만 출력할 것.
```

> [!CAUTION]
> **이름 앞 슬래시(`/`) 절대 금지**: `name: /사칭교정` ❌ ➔ `name: 사칭교정` ⭕
> 크랙 채팅 UI가 버튼 클릭 시 자동으로 `/`를 붙이므로, 이름에 슬래시를 넣으면 `//사칭교정`이 되어 작동하지 않습니다.
