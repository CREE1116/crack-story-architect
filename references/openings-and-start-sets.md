# 4. 다중 시작 세트 및 오프닝 바이블 (Multi-Start Sets & Openings)

이 문서는 크랙의 **다중 시작 세트(Multi-Start Sets, 최대 3개) 표준 규약**, **도입부 원고(7단 줌인 프롤로그·4단 핫스타트 시작 프롬프트)**, **세트별 추천 답변 3종** 작성 바이블을 소유합니다.

---

## 1. 다중 시작 세트 3종 설계법 (Multi-Start Sets — 표준 기본 규약)

> [!IMPORTANT]
> **크랙 스토리챗의 기본 표준은 '다중 시작 세트(Start Sets)'입니다.**
> 단일 시작점은 플레이어에게 단 하나의 정해진 루트만 강제하지만, 다중 시작 세트를 제공하면 **소속, 신분, 시작 성향, 난이도**를 직접 선택하여 다회차 플레이를 즐길 수 있습니다.

### 📐 3대 표준 시작 세트 라인업 (플랫폼 상한 3개)

| 세트 ID | 세트 유형 | 추천 콘셉트 및 상황 | 온보딩 난이도 |
|---|---|---|:---:|
| `01_default` | **정규 / 입문 루트** | 거점 정규 분대 합류, 가장 표준적인 세계관 체험 및 주연 인물과의 조우 | ⭐ (입문 추천) |
| `02_alternate` | **대안 / 전략 루트** | 중립 세력, 암시장 브로커, 독립 헌터, 색다른 직책이나 출신지 | ⭐⭐ (중급) |
| `03_crisis` | **위기 / 하드코어 루트** | 즉각적인 포위/습격, 포로, 탈출, 단독 고립 등 극한의 물리적 긴장감 | ⭐⭐⭐ (상급) |

### 📁 디렉토리 구조 및 결속 원칙

프롤로그와 시작 상황, 추천 답변은 **반드시 한 세트로 결속**되어야 합니다. A루트 프롤로그에 B루트 시작 상황이 붙으면 첫 턴이 붕괴합니다.

```text
<project>/
  start-sets/
    01_default/
      meta.md                  # 제목, 요약 설명, 기본 세트 지정 (default: true)
      prologue.md              # 7단 줌인 도입 원고 (≤ 1,000자)
      start-prompt.md          # 4단 핫스타트 첫 턴 상황 압박 (≤ 1,000자)
      recommended-replies.md   # 세트 전용 첫 입력 추천 답변 3개 (--- 구분)
    02_alternate/
      meta.md
      prologue.md
      start-prompt.md
      recommended-replies.md
    03_crisis/                 # 선택적 3번째 루트
      meta.md
      prologue.md
      start-prompt.md
      recommended-replies.md
```

- **호환성 보장**: 기본 세트(`01_default`)의 내용은 `build/prologue.md`와 `build/start-prompt.md`로도 자동 복사되어 단일 세트 뷰어와의 100% 호환성을 유지합니다.

## 2. 프롤로그: 7단 시네마틱 줌인 공식 (≤1,000자)

각 시작 세트의 프롤로그는 플레이어가 [시작하기]를 누르기 전 읽는 **세계관 몰입용 원고**입니다. 원경에서 주인공의 손끝으로 좁혀 들어오는 7단계 줌인 기법을 적용합니다:

1. **1단계 (원경/세계)**: 하늘, 잿빛 공기, 이 세계를 뒤덮은 거대한 재앙이나 법칙의 풍경.
2. **2단계 (중경/도시)**: 플레이의 무대가 되는 폐허 도시, 네온 거리, 항구, 아카데미의 전경.
3. **3단계 (근경/구역)**: 오늘 사건이 터질 구체적인 건물, 골목길, 녹슨 방화문 앞.
4. **4단계 (인물 군상)**: 그곳을 오가는 사람들의 피폐하거나 무감각한 생활상, 건조한 소음.
5. **5단계 (주인공 줌인)**: 그 자리에 멈춰 서 있는 주인공(ⓤ)의 발끝, 낡은 장비, 손에 쥔 물건.
6. **6단계 (감각적 자극)**: 뺨을 스치는 차가운 빗물, 타는 냄새, 귀를 찢는 원거리 경보음.
7. **7단계 (최초의 균열)**: 문이 거칠게 열리거나 괴수의 포효가 울리며 서사의 문이 열림.

## 3. 시작 프롬프트: 4단 핫스타트 공식 (≤1,000자)

각 시작 세트의 시작 프롬프트는 플레이어가 버튼을 눌렀을 때 **첫 턴으로 렌더링되는 긴박한 현장 상황**입니다:

1. **상황 압박 (In Media Res)**: 평화로운 안부는 금지. 눈을 뜨자마자 당장 결정을 내려야 하는 물리적 위기나 압박 상황 투입.
2. **핵심 NPC 선제 개입**: 현장에 있는 인물이 ⓤ에게 질문을 던지거나, 손을 잡아채거나, 총구를 겨누며 선제 발화.
3. **선택권 반환**: 유저가 어떤 말이나 행동을 할지 선택할 수 있도록 상황적 여백을 남기고 마무리.
4. **초기 하네스 출력**: 상단 `> INFO`와 하단 ````UI````의 1일차 초기값을 정확히 출력.

## 4. 추천 답변 3개 (Recommended Replies) 설계

각 시작 세트의 패널마다 세트 전용 추천 답변을 최대 3개까지 등록합니다 (`---`로 구분):

```markdown
*이름 크리. 26세 남성. 마른 체격, 손등에 세척제 화상. 첫 이능은 「반품」 — 방금 받은 충격 하나를 보낸 쪽으로 되돌린다. 리소스 C급.* 구슬에서 손을 떼지 못한 채 검사관을 본다. "……이거 고장 아니죠?"
---
[지시: 담담한 태도]
*이름 서하. 24세 여성. 짧은 흑발, 낡은 작업복. 첫 이능은 「분리수거」 — 손댄 물체를 재질별로 떼어낸다. 리소스 A급.* "도장만 받으러 온 건데요."
---
*윤. 이름 외에는 말하지 않는다. 첫 이능은 아직 모른다.* 구슬에서 조용히 손을 뗀다.
```

- **답변 1 (표준 프로필·행동형)**: 인물 설정(이름·체형·이능) + 대사를 조합하여 즉각 상황에 반응.
- **답변 2 (지시/메타 활용형)**: `[지시: 내용]`을 포함하여 유저의 서사 조향 능력을 시연.
- **답변 3 (대안/미지정 전략형)**: 상세 설정을 유보한 채 미지의 가능성을 열어두는 선택지.
